# The Moorish Times

Front-end code the live site at moorishtimes.com loads. Nothing else belongs here: this repository is public.

- `scripts/`: site scripts, loaded from `https://cdn.jsdelivr.net/gh/amerruki/MoorishTimes@1/<path>`.
- `styles/`: stylesheets, same URL shape.
- `pwa/`: manifests, service worker, icons and screenshots for the installable web app, served same-origin through the PWA worker.

A change goes live when a new `v1` tag is published. See `RELEASING.md`.
